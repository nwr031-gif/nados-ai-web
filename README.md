# Nados AI — واجهة محادثة ذكاء اصطناعي عربية

منصة محادثة ذكاء اصطناعي (عربية / RTL) مبنية على:
- **Cloudflare Workers AI** (سلسلة موديلات + تدوير بين الحسابات) مع بدائل **Pollinations** (بلا مفاتيح) وGroq / NVIDIA NIM / OpenRouter (مفاتيح اختيارية).
- **نموذج Nados v1.1 المدرَّب داخلياً** (245 معامل) يعمل داخل حلقة المحادثة: يحلّل الرسالة ويضبط أسلوب الرد ويقيّم الإجابة النهائية.
- **مركز تدريب** يشغّل دورات تدريبية حقيقية عبر Python + معاينة Artifact **داخل البرنامج**.
- **تشغيل 24/7** بمشرف ذاتي الإصلاح + مُعIanfe تقييم 100 سؤال.

---

## المتطلبات
- Node.js ≥ 20.10 (مُختبَر على 22)
- Python 3.10+ (اختياري — لدورات التدريب)
- حساب Cloudflare (Workers AI) — أو مفتاح Groq/NVIDIA/OpenRouter

## التشغيل
```bash
npm install          # لا تبعيات — لأجل سكربتات npm فقط
cp .env.example .env # املأ CF_API_TOKEN و CF_ACCOUNTS
npm start            # http://127.0.0.1:4000
```
للتشغيل المستمر (24/7) على ويندوز: `run-24x7.cmd` — يضع نسخة في مجلد Startup ليعمل بعد كل تسجيل دخول.

## الأمان
- **المصادقة**: الواجهة تحصل على جلسة عبر كوكي `HttpOnly` عند تحميل الصفحة؛ أدوات CLI تستخدم ترويسة `x-nados-key`.
- **Rate limiting**: token-bucket لكل عميل (افتراضي 30/دقيقة) + حد تزامن للطلبات.
- **ترويسات الأمان**: CSP، `nosniff`، `X-Frame-Options`، `Referrer-Policy`، `Permissions-Policy`.
- **المعاينة**: `sandbox="allow-scripts"` **بدون** `allow-same-origin` ⇒ محتوى الذكاء الاصطناعي لا يصل إلى أصل التطبيق.
- **الأسرار**: تُقرأ من `.env` فقط (غير متتبَّع في git) — راجع `.env.example`.
- **حدود المسارات**: `path.relative` بدل مطابقة البادئة ⇒ لا يمكن الخروج من `public/`.

> ⚠️ **تدوير التوكنات**: إذا كان `CF_API_TOKEN` أو `github_pat_` قد شُورك، فدوّره فوراً من لوحة Cloudflare / GitHub.

## حدود معروفة
- النموذج المدرّب (245 معامل) مدرَّب على بيانات تهيئة صغيرة ⇒ درجاته **مؤشر تجريبي** لا قياس جودة حقيقي.
- الوضع المحلي (`variant=local`) ينتج رداً قالباً محلياً — **ليس** إجابة نموذج لغوي.
- الحصة المجانية لـ Workers AI = 10,000 عصبون/يوم **لكل حساب**؛ موديل 120B يستهلك ≈ 80 عصبون لكل 1000 توكن.
- يُفضَّل `nemotron-120B(A12B)` كخيار افتراضي: جودة 120B بجهد 12B نشط (أرخص 10×).
